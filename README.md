# Project RE-ARC
![LOGO](img/logo.gif)

## About
This is a small project I made to create mods for MBTL. As you'll notice I included one mod to help with some of the flashing photosensitivity problems. It also serves as a great template to start creating your own mods!

This project is named RE-ARC because Neco Arc is a funny goober the internet adores and RE stands for Reverse Engineering, which I had to do ALOT of in order to get this to work.
