# Project RE-ARC
![LOGO](img/logo.gif)

## About
The RE-ARC mod manager requires a legitimate copy of Melty Blood Type Lumina to function. Without a link to the game's directory, this tool is unable to extract game files as it does not contain any of the files from the game.

This tool, when it is complete, is intended to be used for **offline modding and accessibility**.

## Features

### Game Extraction
The RE-ARC Bin tool is a standalone-exe in the project's go folder which is capable of decrypting and rencrypting any version of melty blood type lumina.
